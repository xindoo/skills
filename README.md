## 创建新 Skill

在 `skills/` 目录下创建文件夹，标准结构：

```
skill-name/
├── SKILL.md           # 必须
├── README.md          # 可选
├── references/        # 可选
├── scripts/           # 可选
└── assets/            # 可选
```

详见 [AGENTS.md](./AGENTS.md)
