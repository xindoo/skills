# skills

个人 Skills 集合。

## 现有 Skills

| Skill | 作用 |
|-------|------|
| [wltucao](./skills/wltucao/) | 无力吐槽汇报优化大师 - 将口语化汇报文本升级为专业高大上的正式版本 |
| [transcript-organizer](./skills/transcript-organizer/) | 语音稿整理 - 将语音转文字内容进行整理优化，支持保留/优化/提炼三种模式 |

## 安装方式

```
npx skills install xindoo/skills --skill wltucao # 这里wltucao为skill名称，可替换成本仓库其他skkill名称
```
