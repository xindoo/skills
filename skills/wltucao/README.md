# 无力吐槽 (wltucao) 汇报优化大师

## 功能介绍
将日常口语化、零散的汇报文本，一键升级为专业、高大上、有画面感、听起来非常厉害的正式汇报版本，专业打造领导爱听的汇报话术，同时提供优化逻辑解读，帮助你在当面汇报时更好地讲解内容。

## 适用场景
- 给领导提交工作汇报、项目汇报、季度/年度总结
- 需要润色汇报话术，让汇报听起来更专业更有高度
- 准备当面汇报材料，需要提前梳理讲解逻辑

## 优化等级选择
| 优化等级 | 适用场景 | 汇报对象 | 优化幅度 | 核心特点 |
|---------|---------|---------|---------|---------|
| 🟢 轻度 | 小组内同步、日常工作汇报 | 直属领导、团队成员 | ≤30% | 仅优化措辞，保留原文结构和内容不变，更通顺专业 |
| 🟡 中度 | 部门级汇报、项目评审 | 部门负责人、中层管理 | 30%-70% | 提升到管理层视角，突出业务价值，重构结构逻辑 |
| 🔴 重度 | 公司级汇报、高管评审 | VP、CEO、公司高层 | 70%-150% | 提升到战略高度，突出行业价值和长期意义，打造记忆点 |

## 使用方法
1. 准备好你的汇报源文件（支持.md/.txt/.docx格式）
2. 调用本技能，输入："帮我用[轻度/中度/重度]优化这个汇报材料，文件路径是[你的文件路径]"，如不指定等级默认使用中度优化
3. 技能会自动生成两个文件：
   - `<原文件名>-优化.md`：直接可以发给领导的正式版本，文件开头标注优化等级
   - `<原文件名>-优化解读.md`：逐段优化说明，包含汇报技巧，帮你当面汇报时流畅讲解

## 示例
输入文件：`一季度工作汇报.md`
选择中度优化后输出文件：
- `一季度工作汇报-优化.md`
- `一季度工作汇报-优化解读.md`
